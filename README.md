# Pablo Nicolas Garcia — PokeMemory

🌐 **Aplicación:** [Jugar a PokeMemory](https://pablonicolasgarcia.github.io/PracticaMidTerm-PabloNicolasGarcia/)  
🎬 **Vídeo de demostración:** https://www.youtube.com/watch?v=SDCdufYEmdo

Juego de memoria desarrollado con **JavaScript Vanilla**, utilizando **[PokéAPI](https://pokeapi.co/)** para obtener los Pokémon. Encuentra todas las parejas en el menor tiempo posible.

## ✨ Funcionalidades

- Crear un perfil y seleccionar un Pokémon favorito.
- Recuperar el perfil durante la sesión con `sessionStorage`.
- Elegir un número par de cartas y jugar con parejas aleatorias.
- Consultar el tiempo transcurrido y reiniciar la partida.
- Finalizar una partida y volver a elegir el número de cartas sin cerrar sesión ni guardar la partida abandonada.
- Guardar los resultados en `localStorage`.
- Mostrar un ranking ordenado por número de cartas y tiempo.
- Distinguir las parejas encontradas y el último resultado.
- Jugar desde ordenador o móvil.
- Cerrar sesión conservando el historial.

El historial y el ranking pertenecen al navegador utilizado; no se comparten entre dispositivos.

## 🧱 Tecnologías

HTML, CSS, JavaScript, módulos ES, Fetch API, sessionStorage, localStorage, Vite, pnpm y ESLint.

Publicación automática mediante GitHub Actions y GitHub Pages.
